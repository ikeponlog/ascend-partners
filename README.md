# STARTUP TAX CHECK

Figma `9:70` を実装仕様として作成した、依存パッケージなしの静的LPと12問診断です。

## 起動

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。`file://` 直開きではなくローカルサーバー経由で確認してください。

## 外部接続

- Lead送信は `app.js` の `leadAdapter.submit()` が接続境界です。現在はブラウザ内イベントを発火するだけで、外部通信はしません。
- 相談予約は本番環境で `<html data-consultation-url="https://承認済み予約URL">` を設定すると有効になります。未設定時は案内を表示し、外部遷移しません。
- `canonical`、OGP URL/画像、note/Xリンク、プライバシーポリシー、運営会社概要は本番URL確定後に接続してください。

## 診断ロジック

税務体制・資金繰り・資本政策・SO準備の4カテゴリに各3問、合計12問です。各回答は0/2/4点、素点48点を100点換算します。カテゴリは12点を100%換算し、A=80%以上、B=60%以上、C=40%以上、D=40%未満です。
