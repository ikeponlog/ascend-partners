# フォント実装ルール

- 原則はFigmaの指定書体。空欄を理由に特定の日本語フォントへ自動置換しない。
- ファミリーだけでなく、ウェイト、可変軸、イタリック、言語別グリフを確認する。疑似太字に頼らない。
- `tokens.css` に役割別の `--font-*` を定義し、使用箇所は変数を参照する。
- 取得できない場合、許可された暫定フォールバックで独立した実装を進めてもよいが、`BLOCKER` とし、Visual QAを合格にしない。
- 書体変更が明示的に承認された場合も、字幅・行数・高さの変化を記録して比較する。帳尻合わせの文字サイズ縮小、字間変更、文章短縮をしない。
- 改行差は、フォントの読込、正しいウェイト、幅、padding、line-heightを順に確認する。意図された改行に限り`<br>`などを使い、全画面幅に一律固定しない。
- Web配信・セルフホスト・サブセット化の可否はライセンスに従う。未確認のフォントをコピーしない。
- `font-display`、必要なpreload/preconnect、フォールバックのメトリクス調整は配信方式に合わせて選ぶ。`size-adjust`は測定値で設定し、推測しない。
- サブセット化は必要な場合だけ行う。静的コピー以外のフォーム入力・動的表示・記号・多言語も対象に含め、文字欠けを確認する。
- 比較撮影は`document.fonts.ready`後に行い、ネットワークと実際の表示フォントも確認する。
