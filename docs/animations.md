# 動き・操作状態の仕様

## 原則
承認済みFigmaプロトタイプ・動作仕様にあるものだけを実装する。
未指定のスクロールリビール、浮遊、拡大、影の強調、色変更、
パララックス、追従、スムーズスクロールを追加しない。
動きが未指定なら装飾アニメーションはNONEとする。

**2026-10-18 変更承認**：チャットでのご依頼により、下表「追加（2026-10-18）」の動き・追従ヘッダー・FAQの開閉・羽のシンボルの動きを追加した（判断ログ D-046〜D-049）。
共通ルール：`prefers-reduced-motion: reduce` ではすべて静止・即時（`base.css` で遷移・アニメーションの時間を0に）。ホバー効果は `hover: hover` の端末のみ。
動くのは transform / opacity / translate / box-shadow / 色だけで、レイアウト（寸法）は動かさない。JSが動かない場合は何も隠さない。
トークン：`--ease-out: cubic-bezier(0.22, 1, 0.36, 1)`、`--dur-fast 0.2s` / `--dur-base 0.4s` / `--dur-reveal 0.8s`、`--reveal-distance 24px`、`--shadow-header` / `--shadow-raise`。

## 必要な操作の実装
- リンクはa、状態を変える操作はbuttonを基本とする。→ FAQはbutton、CTA・リンクはa。
- LPのCTA（LINK-001 / LINK-005）は 2026-10-18 に診断フロー（`diagnosis/`・`diagnosis/#consult`）へ接続（以前は `href` なし：D-011）。
- 診断フローのJSが動かない場合、設問は表示されない（D-031）。LP本体はJSに依存しない。
- hoverだけに依存せず、focus-visibleとキーボード操作を提供する。→ 汎用リンク・FAQボタンのフォーカス表示はFigmaに指定がないため、Brand CTAのFocus色（#005fcc・3px）を流用（D-010）。
- prefers-reduced-motion: reduce：`base.css` ですべての遷移・アニメーションの時間を0にし、フェードアップ（motion.js）も動かさない（`scripts/check.mjs` で動き0件を確認）。
- JS失敗時：FAQ Q1 の回答は初期HTMLで表示状態。他の本文もJSに依存しない（JS無効で確認済み）。
- メディア（動画等）なし。
