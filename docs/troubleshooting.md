# よくある失敗と修正方針

| 症状 | 確認する原因 | 修正方針 |
|---|---|---|
| 余白を揃えたら間延びした | 異なる文脈を同一トークンにした | 役割を分離し、元の密度へ戻す |
| 見出しの行数が違う | フォント未読込、疑似ウェイト、幅・padding | 原因を修正。字間・サイズ変更で隠さない |
| 配色は同じなのに印象が違う | 色面積、画像crop、CTAの強弱 | 参照の構図と寸法を確認する |
| SPで装飾や重なりが消えた | レイアウト変更時の情報・構図の欠落 | SP参照か記録済み方針に戻す |
| diffの数値だけ大きい | 意図した余白変更、累積yずれ、条件不一致 | 条件を揃え、全体と部分でA/B/C/Dを分類する |
| diffが小さいのに違和感がある | フォント・改行・CTA等の局所的な誤り | 数値より情報と構図の一致を優先する |
| a11y修正で見た目が変わった | 色・サイズの無断変更 | 非視覚的な解決を検討し、必要な変更は承認対象にする |
| 最適化後に画像が荒れた | 圧縮、解像度不足、透過変化 | 素材単位で調整し、元画像と比較する |
| 動きが多くなった | 汎用リビールやhover演出を一律適用した | 指定されていない演出を除去する |
| 動くが納品できない | UNKNOWN、未接続、未取得、比較未実施 | 完了した範囲とBLOCKERを分けて報告する |
